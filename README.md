
# JSON Value Navigation

Navigate between JSON values in Visual Studio Code without moving through every character manually.

JSON Value Navigation provides commands to jump to the next or previous JSON value, making it easier to inspect and edit large JSON documents.

## Features

- **Next value** — move to the next JSON value.
- **Previous value** — move to the previous JSON value.
- **String values** — place the cursor inside the string content, excluding the quotation marks.
- **Empty strings** — place the cursor between the quotation marks.
- **Arrays** — navigate through array elements, including nested values.
- **Empty arrays** — position the cursor inside the brackets.
- **Nested structures** — navigate values inside nested arrays and objects.

## Keyboard Shortcuts

| Command | Default shortcut |
| --- | --- |
| JSON Value Navigation: Next Value | `Ctrl+Alt+Shift+Right` |
| JSON Value Navigation: Previous Value | `Ctrl+Alt+Shift+Left` |

> **Note:** If these shortcuts conflict with other extensions or your keyboard layout, you can change them in **File → Preferences → Keyboard Shortcuts** (Windows/Linux) or **Code → Settings → Keyboard Shortcuts** (macOS).

You can also search for the commands by name in the Command Palette (`Ctrl+Shift+P` on Windows/Linux or `Cmd+Shift+P` on macOS).

## Examples

### Navigate through strings

Given:

```json
{
  "name": "Alice",
  "city": "Berlin"
}
```

Navigation moves between the string values `Alice` and `Berlin`. For a non-empty string, the cursor is positioned inside the quotes rather than on the quotation marks.

### Navigate through arrays

Given:

```json
{
  "items": ["apple", "banana", "cherry"]
}
```

Navigation moves through the array's values in order.

For an empty array:

```json
{
  "items": []
}
```

The cursor is positioned inside the brackets.

### Navigate through nested values

Given:

```json
{
  "user": {
    "name": "Alice",
    "active": true
  },
  "scores": [10, 20]
}
```

Navigation follows the values within nested structures, allowing you to move between strings, numbers, booleans, arrays, objects, and other JSON values.

## Installation

### Install from a VSIX file

1. Package the extension:

   ```bash
   vsce package
   ```

2. In VS Code, open the Extensions view.
3. Select the `...` menu.
4. Choose **Install from VSIX...**.
5. Select the generated `.vsix` file.

Alternatively, install it from the terminal:

```bash
code --install-extension json-value-navigation-1.0.0.vsix
```

Replace the filename with the actual VSIX filename generated by your project.

## Requirements

- Visual Studio Code.
- A JSON document open in the editor.

## Known Limitations

Navigation behavior may depend on the document's structure and the extension's parser implementation. Invalid JSON, incomplete edits, or JSON with comments may not be handled exactly like valid standard JSON.

## Development

To run the extension locally:

1. Open the extension project in VS Code.
2. Press `F5` to launch an Extension Development Host.
3. Open a JSON file in the new window.
4. Run the navigation commands or use their keyboard shortcuts.

To check JavaScript types, if the project has a `jsconfig.json` configured for TypeScript checking:

```bash
npx tsc --project jsconfig.json
```
